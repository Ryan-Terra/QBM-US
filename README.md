## Operating principles

- The QBM-US methodology is **versioned, not frozen** — the deliberate reason this repo exists separately from QBM. Amendments are recorded directly in the Methodology's Changelog.
- Historical assessments, journals, minutes, timeline events and archived CMEAs are append-only.
- Every category of information has one authoritative location.
- New permanent documents are created only when unique information cannot logically reside in an existing document.
- Investor preferences belong in `UserProfile.md` and are applied alongside — not instead of — the QBM-US methodology.
